홈 화면에 추가하면 앱처럼 쓰고, 인터넷 없이도 열립니다.

어떤 상황을 위해 기도할까요?

말씀은 개역개정 성경에서 인용했습니다.
모든 기도문은 기기 안에서 만들어지며 어디에도 전송되지 않습니다.

길이

저장한 기도문 (제목을 누르면 펼쳐집니다)

사용 방법

  1. 상황을 고릅니다.
  2. 필요하면 대상 이름(예: 김철수 님)과 세부 사항(예: 임플란트 수술)을 적습니다.
  3. 길이와 부르는 말을 고르고 기도문 만들기를 누릅니다.
  4. 다시 만들기를 누를 때마다 다른 문장으로 새로 만들어집니다. 마음에 드는 기도문은 ☆ 저장하세요.

아이폰 홈 화면에 추가하기

  1. Safari로 이 페이지를 엽니다.
  2. 아래쪽의 공유 버튼(네모에서 화살표가 위로 나온 모양)을 누릅니다.
  3. 목록을 내려 ‘홈 화면에 추가’를 누르고, 오른쪽 위 추가를 누릅니다.

추가한 뒤에는 항상 홈 화면의 ‘기도문’ 아이콘으로 여세요. 인터넷이 없어도 열리며, 즐겨찾기도 아이콘으로 연 앱 안에 저장됩니다. (Safari에서 연 페이지와 홈 화면 앱은 저장 공간이 서로 다릅니다.)
